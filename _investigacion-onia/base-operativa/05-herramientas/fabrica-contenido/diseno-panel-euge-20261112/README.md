# Panel de fábricas OnIA · diseño para revisión

Prototipo interactivo basado en el mapa de Euge y la investigación existente. Todos los estados y resultados de interacción están identificados como demostración. No llama a APIs ni a servicios de OnIA. Las correcciones y encargos se pierden al recargar.

Abrir HOY.html para la versión autónoma, o `npm install` y `npm run dev -- --host 127.0.0.1 --port 4186`. Build: `npm run build`.

Recorridos: Fábricas → revisión → escribir corrección → pedir cambio; Nueva tarea → completar resultado → simular lanzamiento → Trabajo; Cerebro → agregar propósito. Fuentes, brechas y criterios de desarrollo en PLAN.md. Comprobaciones y capturas en evidencia/, valoración en design-qa.md.
