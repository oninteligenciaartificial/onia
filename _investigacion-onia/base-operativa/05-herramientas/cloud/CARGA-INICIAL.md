## Primer paquete

Abrir [ONIA archivos](https://drive.google.com/drive/folders/1eON_RgRbSN3Yz_qmudo5-dNBomDDIufu) y cargar en **01 Entrada**:

1. Logo y una o dos fotos de marca que se puedan usar.
2. Dos o tres grabaciones originales para preparar una primera pieza.
3. Un documento, captura o demo del producto/taller/servicio que se quiera vender primero.

No hace falta ordenar todo antes de empezar. Conservar los originales. Una tarea posterior revisará el primer paquete y preparará un resultado concreto; subir archivos no inicia por sí solo esa tarea.

| Carpeta | Uso |
|---|---|
| 01 Entrada | Material nuevo por revisar. |
| 02 Marca y contenido | Activos y material de contenido organizado. |
| 03 Productos y ofertas | Demos, temarios y materiales comerciales. |
| 04 Entregables | Exportaciones y resultados para revisar. |

La carpeta es privada según los permisos consultados. La tarea cloud comprobó sus cuatro hijos directos; aún no hay una prueba de descarga, render o recuperación de un medio real. El contexto compartido tiene las fuentes señaladas en [CEREBRO-DIARIO.md](../../02-contenido/CEREBRO-DIARIO.md); los archivos privados y registros locales no se migran automáticamente.

## Cuentas y credenciales

Las cuentas se **conectan**, no se cargan como archivos. Para Meta, calendario o un proveedor, primero identificar cuenta/activo y operación, luego completar su conexión oficial. La contraseña y las verificaciones se introducen directamente en el proveedor. No subir contraseñas, tokens ni perfiles de Chrome a Drive o Git.

Las claves n8n y Meta ya fueron guardadas por Sergio y consumidas en sus pruebas de lectura HTTP 200. No crear otras para repetir esas comprobaciones. Higgsfield, Gmail, Calendar y el listado de Drive también pasaron lecturas acotadas. El ejecutor, la versión y los límites de cada resultado están en [ESTADO.md](../../00-MAPA/ESTADO.md) y el inventario en [accesos](../accesos.md); una VM anterior no recibe automáticamente secretos o cambios posteriores.

No pedir a Sergio otra vez su historia, horarios, recursos o metas ya descritos. Pedir sólo correcciones y datos que falten para la tarea concreta: qué oferta trabajar primero y cuáles son sus materiales. La entrega mínima de coordinación vive en [ESTADO.md](../../00-MAPA/ESTADO.md). [CEREBRO-DIARIO.md](../../02-contenido/CEREBRO-DIARIO.md) identifica las fuentes compartidas y sus responsabilidades; consultar la parte pertinente y comprobar el acceso desde el ejecutor del encargo.

## Orden de activación

1. Aplicar la carga de las nueve skills por área y comprobarla al iniciar las sesiones; n8n ya fue probado.
2. Leer el primer paquete desde una tarea cloud y confirmar archivos y permisos.
3. Probar una entrega completa —por ejemplo una pieza de video— y guardar el resultado en Drive.
4. Comprobar los activos y la operación concreta de cada conexión cuando el encargo la requiera; las lecturas previas no acreditan escritura, publicación o gasto.

Las conexiones, publicaciones y automatizaciones se marcan operativas sólo después de una prueba real. Grok Bot y la cuenta de investigación de reels siguen pendientes según la decisión vigente.
