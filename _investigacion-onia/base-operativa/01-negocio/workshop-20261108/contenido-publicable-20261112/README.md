## Editar y reproducir

`editables/01.svg` a `editables/05.svg` y `editables/06-historia.svg` contienen texto y formas editables. Abribles como SVG en navegador o editor vectorial. `generar.py` es la fuente que comparte el contenido y las coordenadas de los SVG y PNG; cambiar allí y ejecutar `python3 generar.py` desde cualquier directorio. Requiere Pillow y fuentes DejaVu Sans del sistema, sin servicio remoto ni proveedor pago. El render usa DejaVu Sans/DejaVu Sans Bold; otro equipo debe tenerlas para mantener las métricas SVG. Los PNG ya incorporan los píxeles de las letras.

No usar IA generativa para estas tarjetas tipográficas: se construyeron con texto y formas locales. No se usaron medios privados, logos ajenos ni capturas simuladas. El copy y los guiones son Markdown editable.
