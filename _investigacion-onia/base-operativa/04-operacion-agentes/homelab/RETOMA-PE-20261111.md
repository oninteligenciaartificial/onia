## Interpretación y siguiente paso

- `no_ejecutado=true`: la validación del archivo o su lectura falló. Conservarlo; no cambiar dueño, modo ni contenido para hacer pasar el control.
- `errno=8`: ejecución/formato rechazado; mirar binfmt y contexto. No prueba por sí solo que Windows esté mal configurado.
- `errno=13`: permisos o montaje; revisar `mount_noexec` y metadatos.
- `errno=2`: falta archivo/intérprete; contrastar binfmt sin habilitarlo.
- `TimeoutExpired`: superó cinco segundos; no repetir ni ampliar el tiempo por conjetura.
- `returncode` distinto de cero: falló la ruta de ejecución o el cargador. Los indicios de stderr son sólo pistas, no causa probada. Codex definirá el siguiente control mínimo si hace falta.
- `control_pe.ok=true`: el control positivo ya funciona en ese contexto. Si la revisión independiente de este código es buena, Boss puede continuar el mismo alta autorizado usando la retoma explícita siguiente; el instalador vuelve a comprobar identidad cerrada, respaldo ORIGINAL, árbol exacto y control PE. Si algo difiere, se detiene.
