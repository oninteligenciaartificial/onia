# Estado y registro

Workshop propuesto no elegido. El ensayo documental no acredita clase real, interés, venta ni cobro. Una web diseñada no prueba tráfico o conversión; aquí no se crea ni despliega ninguna.

Separar eventos: solicitud PLAN → entrega de Kit → interés cualificado → pedido/inscripción → pago informado → cobro conciliado. El Kit no equivale a intención de compra. Cada paso lleva ID, fecha y evidencia; el precio se consulta en la fuente vigente, no se mantiene otra copia aquí.

La relación entre una pieza y una venta sólo puede registrarse como vínculo operativo observado, declarado o ambiguo, con su evidencia. Una vista no atribuye una venta. El dinero conciliado exige transacción única, importe/moneda y verificación del ingreso; promesa o comprobante aislado queda pendiente.
