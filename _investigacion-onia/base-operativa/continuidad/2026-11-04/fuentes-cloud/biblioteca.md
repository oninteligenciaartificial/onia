# Cómo leer y mantener la evidencia

**Observado:** consta en una fuente identificada; indicar quién lo observó y cuándo. **Inferido:** interpretación con alternativas y límites. **Propuesta:** pendiente de adopción. **Probado:** pasó una prueba descrita, sólo en ese entorno y alcance. **Activo:** ejecución real habilitada y comprobada con fecha; no se deduce de un documento o test.

Cada entrada conserva fecha, estado, fuente y versión. Los hechos operativos recibidos de coordinación se rotulan como tales, sin atribuir una nueva ejecución a este chat. La autoridad vigente se consulta en [reglas comunes](https://github.com/oninteligenciaartificial/onia/blob/master/_investigacion-onia/base-operativa/reglas-comunes.md), [ESTADO](https://github.com/oninteligenciaartificial/onia/blob/master/_investigacion-onia/base-operativa/ESTADO.md) y [ORQUESTACION](https://github.com/oninteligenciaartificial/onia/blob/master/_investigacion-onia/base-operativa/ORQUESTACION.md). El [índice previo](https://github.com/oninteligenciaartificial/onia/blob/master/_investigacion-onia/base-operativa/investigacion/2026-11-04/README.md) sirve para ubicación y límites, no acredita una auditoría completa.

Registrar: ID de aprendizaje, fuente y fragmento/minuto, fecha, cobertura audiovisual, hipótesis falsable, artefacto/versionado, criterio previo, prueba y entorno, resultado observado, límites, decisión y responsable. Decidir conservar, ajustar, repetir o descartar; enlazar la decisión anterior en vez de borrarla.
